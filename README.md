# Maze Game Puzzle
<img width="730" height="333" alt="image" src="https://github.com/user-attachments/assets/7f61bed5-c476-47d2-a9e5-6141a73ecbd9" />

This is a Maze game which will be played by using joystick to move the ball from start to end. 

# Softwares used
1. Mazegenerator- To make required maze design and download in svg format.
2. Inkscape- To thicken the border walls according to the requirement.
3. Autodesk Fusion 360- To design all parts.

# Parts to design?
1. Maze structure- Maze can be made in any size and shape. (mine is 15 by 15 cm)
2. Servo motor support- To attach motors to the maze and the bottom maze. {2qty}
3. Servo motor attachment- To attach servo's head to other servo motor. {2qty}

# Non 3D printed parts
1. Mdf boards- One to attach with the maze and other for bottom to this model otherwise the whole structure will fall down.
2. Metal ball- To play the maze game.

# Electronics required
1. Arduino board- To control the working of the maze.
2. Servo motors- To manage X and Y axis movement of the maze.
3. Joystick module- To control servo motor movement.
